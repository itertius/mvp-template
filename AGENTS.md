# Instructions for AI assistants

Read [skills.md](skills.md) before planning or changing this repository. It is the
source of truth for the teaching workflow, scope, architecture, and verification.
Read [README.md](README.md) for commands, [handbook.md](handbook.md) for TA practice,
and [docs/sessions.md](docs/sessions.md) for the current lesson. Read
[docs/mcp.md](docs/mcp.md) before using Supabase or Vercel MCP. User instructions
take precedence over repository guidance.

Some IDEs do not load AGENTS.md automatically. In those IDEs, explicitly attach
AGENTS.md and skills.md to the conversation.
